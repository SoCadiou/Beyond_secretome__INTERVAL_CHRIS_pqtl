# Repository Overview

This repository contains scripts related to the preprint **Beyond the classical plasma secretome: genetic architecture and disease associations of the expanded human plasma proteome in 13,445 Europeans**.

Detailed descriptions of all methods are available in the Supplementary Methods provided with the preprint.

## Repository structure

Scripts are provided for:

* **Epitope annotation of regional and conditional associations**
  `Epitope_definition`

* **Colocalization networks in hotspots based on conditional signals and related annotations**
   `Coloc_networks`
